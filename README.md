A single line spoken by the Moon, answering at last the wishes, howls and late-night promises of everyone staring up at it. After four billion years of listening, the Moon points out the one thing nobody has ever done for it: wished it a good night. The program writes that one line, deterministically, to `entry.txt` — no randomness, no clock, no network — so the grader's two runs produce byte-identical output.

## Run it

```sh
node main.ts && cat output/entry.txt
```
